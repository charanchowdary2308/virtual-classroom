# 🎓 Virtual Classroom

A modern **Virtual Classroom** platform that enables seamless online learning and collaboration between students and teachers. The application provides an intuitive interface for managing classes, assignments, study materials, and communication in one place.

---

## ✨ Features

* 👨‍🏫 Teacher & Student Authentication
* 📚 Course and Study Material Management
* 📝 Assignments and Submissions
* 💬 Real-time Chat & Discussions
* 🎥 Video Meetings
* 📅 Class Scheduling
* 📱 Responsive Design
* 🔒 Secure Authentication

---

## 🛠️ Tech Stack

### Frontend

* React.js
* SCSS / CSS
* Socket.io Client

### Backend

* Node.js
* Express.js
* MongoDB
* Socket.io
* WebRTC

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/charanchowdary2308/virtual-classroom.git
cd virtual-classroom
```

### Install Dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd ../server
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the server (and client if required) and add your own configuration values.

Example:

```env
MONGO_URL=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=8000
```

---

## ▶️ Run the Application

### Backend

```bash
cd server
npm start
```

### Frontend

```bash
cd client
npm start
```
